# BemViva Farmácia

Código-fonte do site demonstrativo da BemViva Farmácia.

## Executar localmente

1. Instale Bun 1.4 ou mais recente
2. Rode `bun install`
3. Rode `bun run dev` para abrir a prévia local
4. Rode `bun run build` para validar a compilação de produção

## Conteúdo

- Páginas, catálogo e componentes: `src/site`
- Rotas: `src/routes`
- Identidade e ícones: `public/assets`
- Configuração de metadados: `src/app-meta.json`

Produtos, preços, disponibilidade, formulário, carrinho e finalização são demonstrativos. Os espaços de fotografia aguardam imagens aprovadas pela BemViva. Nenhum pedido ou pagamento é enviado.
